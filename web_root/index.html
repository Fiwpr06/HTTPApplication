Dịch Vụ 5: Khám Phá Thư Mục (Auto Indexing)

Trải nghiệm tính năng tự động sinh trang mục lục tệp tin (tương tự Apache / Nginx) khi truy cập các thư mục con:

📁 Thư mục /media/ 📁 Thư mục /documents/ 📁 Thư mục /downloads/ 📁 Thư mục /uploads/

Cơ chế giao thức mạng HTTP/1.1 trong MediaHub:

  • Giao thức xem tài liệu PDF: Trình duyệt gửi GET /documents/... HTTP/1.1. Server phản hồi HTTP/1.1 200 OK với Content-Type: application/pdf và các Header chống lưu đệm Cache-Control: no-store.
  • Giao thức Stream MP3 & MP4 (Tua thời gian): Khi tua, trình duyệt gửi Header Range: bytes=start-end. Server Socket cắt đúng lát nhị phân từ file và phản hồi mã trạng thái HTTP/1.1 206 Partial Content kèm Header Content-Range.
  • Tự động duyệt danh mục (Auto Indexing): Khi vào thư mục không có index.html, máy chủ tự render bảng danh sách file tương tự Apache.
  • Tải lên qua HTTP POST: Trình duyệt gửi luồng byte kèm tiêu đề X-File-Name, máy chủ lưu tệp và ghi log vào CSDL SQLite.
