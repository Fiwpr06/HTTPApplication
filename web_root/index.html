Hệ Thống Phục Vụ 3 Dịch Vụ Mạng Đa Phương Tiện

Xây dựng từ TCP Socket thuần túy. Phục vụ Stream Video MP4, Stream Nhạc MP3 bằng HTTP 206 Range Requests và Xem Tài liệu PDF trực tiếp.

Dịch Vụ 1: Stream Nhạc MP3
HTTP 206 Partial Content

Nghe nhạc trực tuyến chất lượng cao với cơ chế byte-range. Khi tua bài hát, trình duyệt chỉ yêu cầu đoạn byte cần nghe mà không phải tải lại toàn bộ.

Dịch Vụ 2: Stream Video MP4
HTTP 206 Range Request

Phát video MP4 trực tiếp, hỗ trợ nhảy tới bất kỳ mốc thời gian nào trên thanh Seekbar. Máy chủ tự động bóc tách Header Range và phản hồi từng phân đoạn nhị phân.

Dịch Vụ 3: Xem Tài Liệu PDF
HTTP 200 OK • MIME Application/PDF

Xem tài liệu báo cáo và giáo trình trực tiếp ngay trên trình duyệt mà không cần cài thêm phần mềm đọc PDF ngoài.

Mở Toàn Màn Hình Tải File PDF

Giải thích giao thức mạng HTTP/1.1 trong bài Lab:

  • Giao thức xem tài liệu PDF: Trình duyệt gửi GET /documents/sample.pdf HTTP/1.1. Server phản hồi HTTP/1.1 200 OK với Content-Type: application/pdf.
  • Giao thức Stream MP3 & MP4 (Tua thời gian): Khi tua, trình duyệt gửi Header Range: bytes=start-end. Server Socket cắt đúng lát nhị phân từ file và phản hồi mã trạng thái HTTP/1.1 206 Partial Content kèm Header Content-Range.
  • Kiểm thử giữa 2 máy / điện thoại: Đảm bảo điện thoại hoặc máy tính thứ hai bắt cùng Wi-Fi với máy chủ, mở trình duyệt gõ: http://[IP_MÁY_CHỦ]:8080/ để trải nghiệm cả 3 dịch vụ trên!
