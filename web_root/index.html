Tính Năng Auto Directory Indexing (Chuẩn Apache)

Khi người dùng truy cập vào bất kỳ đường dẫn thư mục nào trên máy chủ mà không có tệp index.html, máy chủ MediaHub sẽ tự động phân tích và sinh ra trang bảng danh mục tệp tin thời gian thực với đầy đủ icon nhận diện, dung lượng định dạng chuẩn và ngày giờ sửa đổi mới nhất.

Tải Lên Tệp Mới Vào Máy Chủ

Hỗ trợ tải tệp âm thanh (.mp3, .wav), video (.mp4), tài liệu (.pdf, .docx) trực tiếp từ trình duyệt qua HTTP POST.

Kéo thả tệp vào đây hoặc nhấp chuột để chọn tệp

Máy chủ sẽ tự động lưu vào thư mục uploads/

Cơ chế giao thức mạng HTTP/1.1 trong MediaHub:

  • Xem tài liệu PDF & Word (.docx): Trình duyệt gửi GET /documents/... HTTP/1.1. Server phản hồi HTTP 200 OK với MIME chuẩn. Với tệp Word (.docx), máy chủ truyền luồng byte và trình duyệt phân tích hiển thị trực tiếp dạng trang in A4.
  • Stream MP3 & MP4 (Tua seekbar): Khi tua, trình duyệt gửi Header Range: bytes=start-end. Máy chủ phản hồi mã trạng thái HTTP 206 Partial Content kèm Header Content-Range.
  • Tự động duyệt danh mục (Auto Indexing): Khi vào thư mục không có index.html, máy chủ tự render bảng danh sách file tương tự Apache.
  • Tải lên qua HTTP POST: Trình duyệt gửi luồng byte kèm tiêu đề X-File-Name, máy chủ lưu tệp và ghi log vào CSDL SQLite.
